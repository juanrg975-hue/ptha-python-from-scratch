Python and rptha, side by side

PTHA18 was computed with rptha, Geoscience Australia's R package, and a set of R scripts in its austptha_template. This package reimplements the parts needed for earthquake sources and their rates in Python. This page maps every Python function to the R code it reproduces, says how close it is, and which test or check proves it. Functions with no R counterpart are this package's own additions, and are marked as such.

port

reproduces an R function; the "checked by" column says to what precision.

new

no R counterpart: replaces a hand edit of PTHA18 (step 1) or is a safety check (the mesh repairs, the cache).

statistical

random by nature (HS slip): compared by distributions, never field by field.

Reading both codes

  • Most Python functions keep the R name, so a text search in rptha/R/ finds the original.
  • Comments in the Python code cite R line numbers, for example compute_rates_all_sources.R:704 next to the edge fit's tolerance, and explain every place where the Python has to do something specific to match R (geodesy on a sphere or the ellipsoid, R's approx, column-major order, MINPACK's settings).
  • The step templates' docstrings (from_scratch_v12/templates/) say which R script each step replaces.
