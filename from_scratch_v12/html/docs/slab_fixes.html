Geometry: from SLAB to mesh

From SLAB to mesh: every fix, in one page

The USGS SLAB data is a map of the depth of the sinking plate, cell by cell. rptha, the code PTHA18 used, needs something else: clean depth lines every 5 km from the trench down, one unbroken line per depth, ending squarely at both ends of the zone. PTHA18 drew those lines partly by hand. This package does it automatically, in 11 small operations. This page lists all of them, says why each is needed, and shows which ones change with --discretizer.

The short answerOperations 1 to 8 (step 1) are the same for every option: they turn SLAB into contours. --discretizer only matters in step 2. lm and optimal build exactly the same mesh (rptha's), and optimal adds a safety net: if that mesh has a broken cell, it repairs it. mid is an older, different method.

Why optimal and lm are the same on the examplesThe folds that rptha's method can produce come from contours whose ends are far apart along the zone. Operation 7 (clean ends) removes that cause before step 2, so rptha's own mesh has no defect on any of the 8 examples, and the repair is never needed. It is kept as a safety net for zones where it would be. A real example where it is needed.
